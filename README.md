# Yashora Reel Generator

**Yashora Reel Generator** is a text-to-video and short-form reel creation app developed under **RITVYOM** by **Surya Dev Nishad**. Built for both content creators and everyday users, it turns text prompts and scripts into finished videos with **on-device rendering** and **no backend server** required for video processing.

## How It Works
1. **Start from Create Reel:** Open the home screen and tap **Create Reel** to write or paste your own script, or generate a script using the built-in AI option.
2. **Generate Voice & Audio:** Generate voiceovers using your **ElevenLabs** or **Gemini** API key.
3. **Fetch Visuals:** Pull matching images and video clips from the integrated media sources inside the app.
4. **On-Device Render & Export:** Assemble and render the complete video directly on the user's device—nothing is sent out to a backend server for rendering.

## Key Features
- **Flexible Script Input:** Write your own script, paste existing text, or generate scripts with AI.
- **Voiceover Options:** Supports **ElevenLabs** and **Gemini** API keys for voice generation.
- **Integrated Media Sources:** Fetch images and video clips directly from built-in sources.
- **100% On-Device Rendering (No Backend):** Video rendering and export happen locally on the user's device.
- **Watermark Control:** Export with a custom watermark, add your own social media handle as a watermark, or export with **no watermark**.
- **Multiple Aspect Ratios:** Export in **9:16** (vertical shorts/reels), **16:9**, **1:9**, **4:5**, and more.
- **High-Resolution Export:** Supports exporting at **360p**, **720p**, **1080p**, and up to **2K** resolution.

## Who It Is For
- **Content Creators:** Produce vertical reels, shorts, and social videos quickly from scripts or ideas with flexible aspect ratios, resolutions up to 2K, and custom branding/handle watermarks.
- **Everyday Users:** Turn text thoughts, stories, or prompts into shareable videos easily on-device without complex external editing tools.
